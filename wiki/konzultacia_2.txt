====== Consultation 2 — Crawler ======

Source: [[https://world.openfoodfacts.org]] — product pages downloaded as raw HTML (no API, JSON dumps or FTP data).

===== Libraries =====

^ Library ^ Used for ^ Why ^
| Python 3.9+ | everything | |
| ''requests'' | HTTP | Sessions (keep-alive, shared headers and cookie), control over timeouts and redirects |
| ''re'' (stdlib) | link and data extraction | Extraction with regular expressions, not by the exact page structure (XPath/DOM) |
| ''urllib.robotparser'' (stdlib) | robots.txt | Standard parser for the robots exclusion protocol |
| ''gzip'', ''json'' (stdlib) | storage | Compressed HTML cache and JSON Lines metadata — no database |

No crawling frameworks (Scrapy, Selenium, …) and no HTML parser. The site renders on the server, so JavaScript execution is not needed.

===== Architecture diagram =====

{{crawler_architecture.png?900|Crawler architecture}}

  * **Seed:** the paginated home page ''/'', ''/2'', ''/3'', … (~96,000 pages × 50 products).
  * **Strategy:** breadth-first — one listing page, its 50 products, then the next listing page.
  * **Deduplication:** one document per product barcode.
  * **Resuming:** ''visited_urls.txt'' lists finished pages; everything is written to disk immediately, so the crawl continues where it stopped.
  * **Crawling and extraction are separate:** the crawler only downloads and finds links. The regex extractor runs later over the stored HTML, so it can be improved and re-run without downloading again.

==== Change from the project plan: no category pages ====

The plan was to discover products through category pages (//Snacks//, //Beverages//, …). All category and brand URLs (''/category/...'', ''/brand/...'') now redirect to ''/facets/...'', which robots.txt disallows for all crawlers:

<code>
User-agent: *
Disallow: /api
Disallow: /cgi
Disallow: /facets
</code>

To respect robots.txt, the crawler starts from the paginated home page instead, which lists every product and is allowed. The crawler checks robots.txt on every redirect, so it cannot end up in ''/facets/'' by accident. Categories are still extracted from each product page, so products can be filtered by category after crawling.

===== Headers, timeout and sleep =====

^ Setting ^ Value ^ Reason ^
| ''User-Agent'' | ''University IR Project Crawler / Contact: xfarkasp@stuba.sk'' | The crawler identifies itself with a contact; it does not pretend to be a browser |
| ''Accept'' | ''text/html,application/xhtml+xml'' | Only HTML is needed |
| ''Accept-Language'' | ''en'' | English labels ("Brands:", "Allergens:") that the regexes rely on |
| ''Cookie'' | session of a registered account | Listing pages beyond ''/10'' return HTTP 401 to anonymous users ("Due to heavy abuse from robots… create a free account") |
| Sleep | 1 s between all requests | At most 1 request per second to the site, as recommended in the lecture; raised automatically if robots.txt sets a higher ''Crawl-delay'' |
| Timeout | 20 s | Pages are 200–800 KB and usually arrive in ~1 s |
| Retries | 3 attempts, waiting 2 s and then 4 s | Only for 5xx, 429 and network errors; 4xx errors are not retried |
| Redirects | followed manually, max 5 | Each hop is checked against robots.txt |

===== Crawler implementation =====

^ File ^ Contents ^
| ''crawler.py'' | ''fetch()'' — politeness, retries, redirects; ''extract_product_links()'' — regex link extraction; ''save_html()'', ''save_metadata()'' — storage; ''crawl()'' — main loop |
| ''extractor.py'' | Regex extraction of product fields from the stored HTML → ''products_data.jsonl'' |
| ''stats.py'' | Page counts, sizes on disk, failures |

**URL extraction.** Listing pages draw their product grid with JavaScript from data embedded in the page, so product links are found with a regex over the raw HTML instead of ''<a href>'' tags. Every product has a URL of the form ''/product/<barcode>/<name>''; the barcode is the product's unique ID.

<code python>
PRODUCT_LINK_RE = re.compile(r"/product/(\d{4,})(?:/([A-Za-z0-9_.%-]*))?")
NEXT_PAGE_RE = re.compile(r'<a\s[^>]*href="([^"]+)"[^>]*>\s*Next\s*</a>', re.IGNORECASE)
</code>
